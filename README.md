# 🥐 MiPan 2025 Store — PWA de Panadería & Repostería

Aplicación Web Progresiva (PWA) ligera, responsiva e instalable en dispositivos móviles y de escritorio. Diseñada para ofrecer una experiencia rápida de catálogo, cotización y gestión de pedidos para panadería y repostería artesanal.

**Características principales:**

* **Experiencia PWA Nativa:** Instalable en Android, iOS y PC mediante Service Worker y `manifest.json`.
* **Soporte Offline:** Acceso al catálogo e interfaz sin necesidad de conexión a internet activa.
* **Cálculo Multimoneda:** Conversión automática de precios entre USD y Bolívares (Bs.) con ajuste de tasa BCV.
* **Interfaz Adaptativa:** Diseño moderno optimizado con temas estacionales (como modo navideño) y soporte para modo oscuro.
* **Stack Tecnológico:** HTML5, CSS3 / Tailwind CSS, JavaScript Vanilla (ES6+).
